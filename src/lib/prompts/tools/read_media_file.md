- `read_media_file` — Read a binary/media file (image, audio, PDF) as a base64 data URL. Use for viewing images, diagrams, or other non-text files. Supports: png, jpg, gif, webp, svg, bmp, ico, mp3, wav, mp4, webm, pdf. Max 10MB. Path relative to workspace root.
