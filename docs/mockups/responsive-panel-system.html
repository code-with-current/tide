Tier thresholds are measured on the panel-row width (not window.innerWidth) — so dragging the sidebar or a collapsed right panel re-evaluates the tier correctly.
Tiers: T1 Wide ≥ 1360px · T2 Medium 1200–1359px · T3 Narrow ≤ 1199px. The window min stays 1080×680, which always lands in T3.
All drag handles enforce their min/max in pixels — no percent constraints anywhere, eliminating the px/% mixing class of bugs. Composer selector row wraps below 300px. Every truncating text node sits in a min-width:0 chain.
