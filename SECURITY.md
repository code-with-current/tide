# Security Policy

## Supported Versions

Only the latest release of Tide receives security fixes. Updates ship
through the in-app updater and https://tide.codes.

## Reporting a Vulnerability

Please use GitHub private vulnerability reporting:
https://github.com/code-with-current/page/security/advisories/new

If that doesn't work for you, email hi@egoist.dev.

Please don't open a public issue for anything you believe is
exploitable before it has been fixed. Include reproduction steps and
the Tide version (Tide → About Tide) you tested.
